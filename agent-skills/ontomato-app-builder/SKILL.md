# Ontomato app builder

Use the [Vue panel skill and complete example](references/panel-authoring/SKILL.md) for panel authoring. The [technical guide](GUIDE.md) covers connection, registration and errors. For an existing application, start with the [decomposition skill](references/app-standard/SKILL.md). When the platform supplies `application-design`, read it before designing or polishing a panel.

Use the attached workspace and current identity. The guide covers external connections, owner-provided business capabilities, build-test data and registration. For new Actions and MetricViews, read the owner context, write a definition and have the Java authoring API test and accept it through the CLI. In a platform conversation, use the native `agent` tool and the product's analyst skill for delegation.
