# Ontomato app builder

Read the [technical guide](GUIDE.md) and use the bundled `ontomato.mjs`. Read the SDK guide for the installed version before composing panels. When the platform supplies `application-design`, read it before designing a new panel or polishing an application.

Use the attached workspace and current identity. The guide covers external connections, owner-provided business capabilities, build-test data and registration. In a platform conversation, use the native `agent` tool and the product's analyst skill for delegation.
