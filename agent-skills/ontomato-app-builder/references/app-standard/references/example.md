# 例子

两个例子。第一个是平台自己已经做完的真实页面；第二个是照模板演示的业务页面，里面的类名和指标是编的，只为说明怎么填。

## 例一：定时任务（平台已做完）

页面：左边任务列表，右边是选中任务的摘要、编辑表单和“立即运行”按钮。

### 投影

| 这一块 | 基础组件 | 数据从哪来 | 读法和参数 | 配置项 | 输入 | 输出和操作 |
| --- | --- | --- | --- | --- | --- | --- |
| 任务列表 | 对象列表 | 一类东西：定时任务 | 列出全部 | 无 | 当前选中的任务 | 输出：选中了哪个 |
| 任务摘要 | 对象摘要 | 一个东西：传进来的那个任务 | 读这一条 | 显示应用、设置、状态、下次运行 | 任务 | 无 |
| 任务表单 | 对象表单 | 一个东西：同上 | 读拥有者给的表单 | 无 | 任务 | 操作：保存 |
| 立即运行 | 操作按钮 | 一个操作：立即运行 | 读操作的说明 | 无 | 任务 | 操作：立即运行 |

四个基础组件里没有一个字提到“定时任务”。换一个来处，同一个对象列表就是“指标列表”。

### 面板

| 要定的 | 内容 |
| --- | --- |
| 成员 | 上面四个投影 |
| 排布 | 左边任务列表；右边从上到下是摘要、表单、按钮；右边三块在选中了任务以后才显示 |
| 状态 | “选中的任务”：一个对象（定时任务），不按人保存，进地址，对外 |
| 怎么连 | 列表的输出写“选中的任务”；摘要、表单、按钮的输入都读它 |
| 事件 | 无 |

面板里没有一行取数、保存或执行的代码。

### 归到能力层的

| 界面里原来的逻辑 | 归成什么 |
| --- | --- |
| “立即运行”要做的事 | 定时任务拥有者提供的一个操作 |
| 表单有哪些字段、怎么校验 | 定时任务拥有者给的表单描述 |

### 入口

两个应用都用这张面板：各自一个入口，地址、菜单名、谁能进各写各的；面板只有一份，改了两边一起变。

## 例二：课程管理（演示用，类名是编的）

原页面：顶部选学期；左边课程列表，可以按院系筛选；右边是选中课程的基本信息、选课人数趋势图、选课学生名单；有“停开课程”按钮，点了以后界面代码会把课程状态改成停开、把已选学生的选课记录置为无效、再发通知。

### 投影

| 这一块 | 基础组件 | 数据从哪来 | 读法和参数 | 配置项 | 输入 | 输出和操作 |
| --- | --- | --- | --- | --- | --- | --- |
| 课程列表 | 对象列表 | 一类东西：课程 | 按条件查询；参数：学期、院系 | 显示课程名、教师、学分 | 学期、院系、当前选中 | 输出：选中了哪门课 |
| 院系筛选 | 引用选择 | 一类东西：院系 | 可选项 | 无 | 当前院系 | 输出：选了哪个院系 |
| 课程信息 | 对象摘要 | 一个东西：传进来的课程 | 读这一条 | 显示课程名、教师、学分、状态 | 课程 | 无 |
| 选课趋势 | 图表 | 一个东西：指标“选课人数” | 算出来的结果；参数：课程、学期 | 折线图 | 课程、学期 | 无 |
| 选课名单 | 对象列表 | 一类东西：选课记录 | 按条件查询；参数：课程 | 显示学号、姓名、选课时间 | 课程 | 无 |
| 停开课程 | 操作按钮 | 一个操作：动作“停开课程” | 读操作的说明 | 无 | 课程 | 操作：停开课程 |

### 面板

| 要定的 | 内容 |
| --- | --- |
| 成员 | 上面六个投影 |
| 排布 | 第一行院系筛选；下面左边课程列表，右边从上到下是课程信息、选课趋势、选课名单、停开按钮；右边在选中课程以后才显示 |
| 状态 | “学期”：简单值，进地址，对外（由外面传进来）。“院系”：一个对象，按人保存，进地址。“选中的课程”：一个对象，进地址，对外 |
| 怎么连 | 院系筛选的输出写“院系”；课程列表读“学期”“院系”，输出写“选中的课程”；右边四块读“选中的课程” |
| 事件 | 无 |

### 归到能力层的

| 界面里原来的逻辑 | 归成什么 | 说明 |
| --- | --- | --- |
| 停开课程时改状态、作废选课记录、发通知 | 一个动作“停开课程” | 输入：课程；会改课程和选课记录。界面只发起这个动作 |
| 趋势图的人数怎么数 | 一个指标“选课人数” | 参数：课程、学期 |
| 谁能停开课程 | 动作上的权限规则 | 不在按钮上判断 |

### 应用和入口

| 入口地址 | 面板 | 给面板传什么值 | 菜单名 | 谁能进 |
| --- | --- | --- | --- | --- |
| 应用下的 /courses | 课程管理 | 学期：取外框面板的“当前学期” | 课程 | 本应用的“课程管理”权限码 |

“当前学期”是全应用共用的选择，放在应用外框面板的状态里并进地址；课程管理面板的“学期”由入口传进来，自己不另存。这样把课程页的地址发给别人，对方看到的是同一个学期。

### 要做成组件包的

这张页面没有：列表、摘要、图表、引用选择、按钮都是官方组件。假如趋势图要画成官方图表画不出的样子，才列一个新部件在这里。
