# What the assistant receives

The platform generates the entry's page description from its declared reads, state, forms, operations, and `recipes.md`;
the page operator skill supplies the shared methods. The platform passes current entry metadata, live public state, declared selections, and open form contents in `pageContext` and
`observe_display`. Keep page-specific guidance in `recipes.md` and verify via the
[page input box](../SKILL.md#check-the-assistant-from-the-page).
