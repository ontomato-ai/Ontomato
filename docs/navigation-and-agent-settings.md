# 导航与内置智能体配置

本次调整按实际运行职责组织入口：业务知识属于事实层，同时在知识治理中复用同一页面；治理层提供成员、角色、智能体主体、权限策略与组织架构入口。权限判定继续沿用原页面权限，不因入口重复出现而扩大权限。

本体管理器菜单在短屏中独立滚动。实例图谱类型牌使用小字号、紧凑内边距和弱背景。系统设置的模型分组集中提供模型配置、模型服务、本体建模模型、知识治理模型、数据分析模型、应用构建模型。原建模和治理模型地址转到新的系统设置地址。

应用构建支持多个域内实例，每个实例单独选择模型，运行准备实际读取该选择。构建实例继续使用专用 Skill、工作区约束和应用构建权限；普通 Agent 配置接口不能编辑构建实例。知识治理同样支持多个实例，使用各自模型，沿用原治理权限、会话所有权和运行校验。已有会话保留原执行实例，切换用于新对话。

知识治理 Skill 增加来源登记与知识抽取导入：当前输入、历史和文本制品可成为登记来源，导入要求来源已登记、运行有效、当前所有者仍具有业务知识权限。稳定知识 ID 用于重复调用，已有 ID 内容不同则拒绝；导入记录为待审核状态。该接口不写任意业务对象、关系或本体映射；结构化事实抽取和导入仍需对应受治理数据接入或 Action，不能将知识条目导入视为完整对象导入能力。

验证包括相关 TypeScript/Vue 类型检查、Node 构建实例边界测试、菜单布局与治理页面测试、企业主体页面测试；Java 仅运行筛选的模型设置、权限、宿主、Jackson 边界及知识导入测试。实际测试域验证短屏菜单滚动、配置保存、多实例选择、来源登记、知识待审核导入与重复回放；临时知识已清理。未运行全量 Java 外部系统测试，未将配置读写和工具接口验收记为所有实例真实模型端到端执行通过。

当前动作创建等 Java 内置对话仍由原模型配置管理，尚未实现每一种内置对话的任意多实例创建。后端无头计算实例继续按现有模型用途配置管理。
