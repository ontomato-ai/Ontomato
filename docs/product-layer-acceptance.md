# 产品层迁移与集成验收记录

日期：2026-11-13。范围：本地企业组合、测试数据域、产品资产与代表性对象视图。本文仅记录汇总与结论，不保存账号凭据、业务记录、真实配置或运行导出。

## 存量盘点

当前管理员可见 18 个产品资产：页面 2、组件组 2、组件 5、应用入口 3、仪表盘引用 2、布局模板 1、操作板 1、对象视图引用 2。此范围是该账号可见资产，不代表其他账号的私有资产全集。

两个对象视图产品入口共用一个包含 18 个组件的类视图。迁移前有 3 个属性直读组件、3 个关系直读组件，以及对象字段参数绑定、字符串结果路径和 Action 内的对象上下文。另发现一个未登记为产品资产的组织类视图仍使用属性直读。

三个有内容的源码工作区均缺少产品交付记录；其中两个同时缺少产品依赖清单。空工作区未作为可交付应用验收。

## 已完成的迁移与验证

- 保留代表性类视图的 18 个组件和五个页签，为属性与关系列表创建四个只读能力，其余读取复用现有能力。
- 对象标识参数改为 `context.primaryKey`。Action 默认字段从能力详情结果绑定，不再从对象实例直读。
- 将旧数字结果路径迁为类型化 `resultIndex`，保留指标行选择；关系图由渲染适配器消费选中行的图数据。该字段只选择能力输出，不计算口径。
- 属性组件可将其能力结果行暴露为局部变量，为操作表单提供默认输入；它不产生授权或业务约束。
- 12 个读能力实际执行成功。浏览器验证五个页签、对象详情、关系明细、指标与专门图表；未发现页面脚本异常、对象实例直读或 DSL 直读请求。手机宽度下无整页横向溢出。
- 产品依赖接口展开 12 个 MetricView 和 2 个 Action。对现有 18 个产品重新准入，16 个通过，两个对象视图引用因失效 Action 表单被拒绝。
- 临时普通账号可发现域内共享资产，管理员私有资产返回 404；无操作授权时 Action 表单由服务端拒绝。临时账号已移除。现有策略允许该账号读取人员详情，因此此项不证明行级数据隔离。
- 已审核一个仅展示已发布指标与导航的源码应用，补齐随提交保存的产品交付记录。缺少记录时发布返回拒绝；补齐后连续发布两版，再回滚到第一版。平台应用目录的活动版本与回滚目标一致，工作区内容也恢复至已审核版本。
- 演示 Action 拒绝空输入；有效提交在业务写入步骤失败。回读确认目标值未发生改变。

## 第二轮处置与复验

两个缺失 Function 的维护 Action 找到了历史程序依据：学历维护文件的完整哈希与已发布 Action 一致；交流维护文件去除后加的演示标记限制后与原哈希一致。两者都使用已退役的命令行与裸 HTTP 调用协议。恢复时保留原发布定义，按原参数、取值校验、归属查询和写入字段创建新的标准 Python 协议 Action，不将旧协议重新放行。交流维护能力显式声明人员与交流记录两个读取类型。

代表性类视图改为引用新能力并发布。两个维护表单均可打开；浏览器确认对象标识为只读绑定，学历学位默认值来自详情能力。交流维护完成非法输入拒绝、有效写入、能力回读及原值恢复。两个对象视图产品均通过重新准入。学历维护完成表单验收，没有对真实人员学历做改值测试。

原独立演示来源核实 Action 的写入错误已定位为 M3 的 `source` 属性未建索引，无法执行带原值条件的更新。没有删除并发条件，也没有改底层索引；该独立演示 Action 仍不算有效写入通过。它与已恢复的交流维护 Action 是不同能力。

两个旧源码应用已迁移到已发布 MetricView：去重、演示记录判定、统计分布、导师学生论文关联、查询筛选与详情关联由能力拥有。页面传入交互参数，接收展示结果，保留图表样式、分页展示、导航、选中状态及错误反馈。请求序号防止过期响应覆盖新筛选结果。源码工作区补齐显式产品依赖清单和交付记录后发布，浏览器验证两个应用均正常加载且无脚本错误。

复验结果：师资应用的档案总量、在职人数、单位数与学历缺失数保持原口径；科研应用默认排除演示记录后的论文、学生、导师与交流数量保持原口径。运行数据和工作区源码只保存在本地测试环境，本文不收录人员明细或部署配置。

当前保留事项：组织类旧视图尚未迁移；行域差异仍需明确的测试策略；独立演示 Action 的 M3 索引问题需按数据源维护范围处理。代表性产品的交流维护写入闭环已通过，不能据此推断所有业务写入或所有存量资产已完成验收。
