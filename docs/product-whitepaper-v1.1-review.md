# 产品层与白皮书 V1.1 核查

日期：2026-11-16。范围：产品层模型、保存校验、发布依赖、人与 Agent 运行入口及本地企业组合。本文不保存业务明细、凭据或运行配置。

## 本次修正

- 目录层次统一为投影资产、组合资产、交付单元；渲染选项使用可读名称。
- ObjectView 新保存只允许对象属性、关系与说明，拒绝内嵌能力绑定及指标、操作配置。指标和操作分别通过 MetricWidget、ActionView，由 Page 引用组合。历史文档仍可解析，重新编辑和发布须满足新校验。
- 无 Navigation 的声明式 Application 同样禁止直接放入投影；投影必须通过 Page 组织。
- 修复声明式应用导航框架占满页面高度的问题；正文独立滚动，手机端按现有栅格断点排列。
- 指标图的空分类显示为“未填写”，不改变指标返回值或计算口径。
- AgentProfile 准备工具和上下文期间显示加载反馈；实际导航切换确认档案名册、维护表单和对话输入框能够打开。

## 本地资产重建

在测试域新建 40 个产品资产：10 个指标投影、6 个集合投影、6 个对象投影、2 个操作投影、9 个页面（含一个模板）、3 个导航、3 个 Application 和一个 AgentProfile。另创建六个已发布 Definition，由能力定义拥有集合范围。

三个业务场景分别为师资管理、科研成果和学术交流；只读分析助手复用相同的 16 个工具投影及三个文本对象上下文。Application 和 AgentProfile 均已发布并冻结依赖。

清理当前管理员拥有的 49 个旧业务展示与验收资产、四个旧平台应用入口。保留发布快照、修订记录、既有业务能力、事实、授权以及个人主页和六个工作区投影。其他所有者的个人工作区不属于此次清理范围。清理前导出到仓库外临时目录；旧发布历史未解除删除保护，现场清理由限定资产 ID 的维护事务执行。

## 验证与限制

- 产品服务 27 文件 / 138 项、Manager 17 文件 / 156 项测试通过；contracts、服务端、Manager、platform-web 类型检查通过。
- 实际执行十个指标与六个集合；Agent Principal 路径执行指标和集合成功。三个应用的活动发布依赖无契约漂移。
- 浏览器桌面与手机宽度检查确认指标位于可视区域，无 pageerror 或整页横向溢出。此结果不等于所有交互和全部权限组合已验收。

仍不能将系统标记为严格满足白皮书全部要求：能力的不可变版本解析仍主要依赖现有能力身份、契约哈希与漂移拒绝；历史兼容路径和旧 Java ObjectView 写入口仍存在；Definition 的生命周期及统一治理集成需要继续完善；后台持久订阅和内置 3D renderer 尚未齐备。当前新资产避开旧内联 ObjectView 配置，未将这些实现限制包装为通过。

本次两项维护 Action 已通过产品保存和应用发布准入，但未改写实际人员或交流记录做新一轮写入验收。既有独立来源核实 Action 的 M3 索引阻塞仍见迁移记录，此次新应用没有引用该 Action。
