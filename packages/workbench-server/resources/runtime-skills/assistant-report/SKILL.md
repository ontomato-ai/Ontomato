---
name: assistant-report
description: Write an evidence-based Markdown report as a workspace file for a business question.
---

Write the report to outputs/reports/<name>/report.md, then link that path in the
reply. Use ordinary read/write/edit/bash tools. No publication command is needed.
Keep drafts outside outputs/ until ready. Explain the question, observations,
calculations, sources, limitations and conclusions. Use verified dataset files and
retain truncation warnings. Reference charts/data with workspace-relative outputs/
paths according to the shared host Markdown rule. Do not invent facts to fill a
section. Whether a report is useful is your decision; no host check or rerun follows.
