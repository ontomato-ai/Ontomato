Build the application in its attached source directory. Read the application-design and ontomato-app-builder skill guides and the installed SDK component catalog. Reuse existing definitions, owner reads, and official SDK components.

Keep application metadata, entry placements, frame, theme, and delivery in `application.json`. Keep each owned panel in `panels/<panelId>/` with `panel.json`, `panel.html`, and optional `panel.mjs` and `recipes.md`. Keep each owned projection in `projections/<projectionId>.json`. Reference resources owned by another application by ID. Keep credentials out of source files.

Edit and validate these source files, preview the result, and record the changes in a source commit. The application page's registered operations synchronize live definitions into source and publish source commits to the live application. Use those operations for synchronization and publication. You may propose publication through the page so the signed-in user can confirm and submit it.
