# 面板目录：这一页怎么用，智能体怎么做

这一页列出平台自带和本域中读者可用的面板，选中一个就显示它的源码、样式、成员引用、使用方和授权。所有读取和写入都是
`platform:ProductPanel` 这个所有者自己的读取和操作（所属人名字读 `platform:User`，成员里的投影读
`platform:ProductProjection`）；这一页不自己判断权限，也不自己拼业务请求。

## 页面现在显示什么

- 左侧：面板列表。搜索框写进 `search`（所有者按名称和说明匹配），范围 `scope` 取 `all`（全部可用）、`mine`
  （我的）、`shared`（共享给我），排序 `sort` 取 `updated`（最近更新）或 `name`（名称），模板用途
  `template` 取 `true`（仅模板）、`false`（非模板，含没声明模板用途的）或不传（全部）。筛选和分页都由所有者做，
  每页 20 条。
- 右侧固定六个页签：概览（ID、名称、说明、所属人、公开状态、模板用途、你的权限、修订号、时间、所属类
  `platform:ProductPanel`）、源码（`content.html`、`content.module`、`content.style`、`content.recipes`、
  `content.messages`）、成员引用（每个成员的引用目标、传入和传出的值）、使用（在用的应用入口、在用的面板、
  在用的类详情、派生的页面技能）、授权、预览。
- 没有编辑权的面板按只读显示：编辑、复制、另存为模板、删除、共享和授权的按钮都不可用。

## 面板详情里的事实

- `members` 是面板声明的成员：引用投影（`projectionId`）、引用面板（`panelId`）、按状态选择面板或投影（`fromState`）、或当前应用入口（`fromPlatform: "currentEntry"`）。成员里出现的投影可以直接选中，
  页面会按它的 ID 读投影记录（名称、组件、所属人）。
- `usedBy` 分成两组，分别回答「哪些应用入口在用」和「哪些面板、哪些类的详情在用」，再加一个你无权读取的使用方
  个数。应用入口那一行可以直接打开；在用的面板可以切换选中。
- 公开状态取自 `visibility`：`private` 私有，`domain` 域内共享，`platform` 平台自带。
- 授权页签先读 `grants`（要这个面板的编辑权）：列出每条 Grant 的授予方类型、被授予方 ID 和 use/edit，以及它是否域内共享；
  域内共享那条（`principalKind: "domain"`）不能单独撤销，要用共享开关。

预览页签在原位挂载选中面板的当前定义，由平台检查该面板的使用权，不要求它已放进应用入口。

## 人要做的操作

编辑与新建都用所有者自己的表单和保存操作：编辑只提交改过的字段（表单自己算 `submittedFields`），新建先清掉选中。
复制给新面板一个 ID 和名称，新面板仍引用原面板的投影。另存为模板是复制之后把 `template` 打开。「从模板创建」按模板
的源码和成员新建一个面板（`template` 关掉），仍引用同一批投影。删除要先点一次确认：被应用入口、别的面板或类详情
用着时所有者会拒绝，页面列出使用方；成功时所有者报告一并清掉了哪些只由它用的投影、哪些因无权而保留。授权是
「角色/成员 + ID + 使用/编辑」三样，加上域内共享的开关；共享时所有者会连它用到、且你有权授出的投影一起授出，
没能连带的投影 ID 会显示出来。

## 智能体怎么起草

要改一个面板，先读它的表单（概览页签上的字段就是所有者表单的字段），再写一份草稿产物，只放要改的字段：

```json
{
  "pageKey": "ontology-panels",
  "operation": "panel.update",
  "target": { "id": "<面板 ID>" },
  "form": { "description": "新的说明" }
}
```

新建面板用同一份草稿、把 `target` 留空，`operation` 用 `panel.create`，`form` 里至少给 `name`、`content.html`、
`content.module` 和 `manifest`（`{state, members, events}`）。把草稿存成 `outputs/drafts/*.page-draft.json`，再用
这一页的地址加 `?draftSessionId=&draftRunId=&draftPath=` 打开：表单会按草稿填好、标出改过的字段，等人保存。
没保存就什么都没写。

## 智能体怎么执行操作

复制、删除、授权、撤销、域内共享都是这一页声明的操作，和页面上的按钮是同一个实现。改数据的操作要人确认后才执行；
删除要先说清它被谁用着，被拒绝时把使用方一起说出来。不要自己在页面之外发业务请求。
