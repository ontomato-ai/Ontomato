# 基础组件：这一页怎么用

## 这一页覆盖什么

当前部署的 SDK 发行里声明的全部基础组件（本体类 `platform:SDKComponent`，主键形如 `@ontomato/sdk:ObjectList`：包名加冒号加组件名；也包含本域可见的包组件与自定义域组件）。
页面采用单面板双视图排布：
- **整宽目录视图**（`selected` 为空）：顶部页面标题与刷新操作，下方工具栏提供关键词搜索框与当前过滤数量，主体为按用途分组的整宽表格（组件、角色、使用范围、适用对象、所属包），点击任意行进入该组件的整宽详情视图。
- **整宽详情视图**（`selected` 非空）：顶部单行页头提供返回目录（同步支持浏览器后退与 `Escape`）、组件名称/所属包/角色、刷新与「查看所属类」；概览卡片里完整展示该组件的用途分组、使用范围与全部「含义」说明；返回目录时保持搜索词与滚动位置不变。当地址里的组件在当前发行中不存在时，在详情主体区域给出原位空态说明，不挂载概览与五张明细表。

每个组件通过官方组件投影展示它在发行里声明的内容：概览与含义、它要的数据和类型、配置项和默认值、输入与插槽、输出（含只读输出）与事件，以及它自己声明的操作签名。
只显示组件声明的东西，不显示某个投影实际绑定了哪个业务操作或哪个本体类型——那属于那个投影。

这一页只读。组件随 SDK 发行增改，页面不新增、不修改、不删除任何组件，也没有可执行的业务操作。
「查看所属类」打开能力图谱，并传入类型模式和「基础组件」类作为页面状态。

## 页面状态

- `search`：当前搜索词。搜索覆盖组件的主键（包名加组件名）、包、角色、使用范围、用途分组、适用对象类型、含义和副作用；空值表示不筛选。从详情返回目录时保持不变。
- `selected`：当前选中的组件，是一个对象引用 `{className: "platform:SDKComponent", primaryKey}`；为空时显示整宽目录，非空时进入整宽详情页。
- 两者都以扁平具名查询参数（`?search=<词>&selected=<组件主键>`）写入地址，所以消息里的页面地址就带着读者现在搜索和选中的是什么。

## 回答「某个组件要什么数据、有哪些配置」

1. 从页面上下文和地址参数读 `selected`（组件主键），或在 `search` 非空时按搜索词理解读者指的是哪一批组件。
2. 用页面技能的「读当前数据」读取页面已声明的成员数据：
   - 成员 `list`（`rows` / `catalogue`）：按搜索词查看按用途分组排列的组件目录（组件、角色、使用范围、适用对象、所属包）。
   - 成员 `header` 或 `summary`（`record`）：查看选中组件的名称、组件标识（`componentId`）、所属包（`package`）、模块（`module`）、导出名（`exportName`）、角色（`role`）、用途分组（`group`）、使用范围（`panelUsable`）、适用对象类型（`bindsElement`）、完整含义（`meaning`）与副作用（`effects`）。
   - 成员 `dataTable`（`rows` / `dataRows`）：查看组件声明的数据名、接受的读取结果（`results`）、是否必需（`required`）和运行时读取参数（`runtimeParams`）；返回空表示不读本体数据，只能当界面用。
   - 成员 `configTable`（`rows` / `configRows`）：查看配置项的名称、类型（`type`）、是否必需（`required`）、默认值（`defaultValue`）与说明（`description`）。
   - 成员 `inputTable`（`rows` / `inputRows`）：查看组件声明的取值输入与插槽（`kind`、`type`、`description`）。
   - 成员 `outputTable`（`rows` / `outputRows`）：查看组件交给页面的输出值、只读输出与发出的事件（`kind`、`type`、`description`）。
   - 成员 `operationTable`（`rows` / `operationRows`）：查看组件自己声明的操作签名（`signature`）；当前 SDK 发行里组件本身不声明业务操作，页面能执行的操作由投影声明。
3. 回答时用读者看到的名字（组件名、包名），把声明里的原文照实说：类型写发行里的写法，不要换成自己的说法。
   发行里没有声明的项就说没有声明，不要拿别的版本或别的组件的声明顶上。

## 不要做的事

- 不要在这一页创建、修改或删除组件，也不要为某个组件「补上」发行里没有的配置或数据。
- 不要把某个投影绑定的业务操作、业务类型说成是组件的声明。
