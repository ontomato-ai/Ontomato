# 四层能力图谱：这一页怎么用

这一页是本体管理器治理层的「能力图谱」，按四层本体（事实 / 能力 / 治理 / 产品）读取平台已登记的类型、它们之间的关系和当前用户能读到的实例。全部只读：页面上没有任何写对象的操作。

## 页面公开状态

地址里的 `state` 就是这一页公开的东西，可以还原，也可以由智能体在打开页面时给出：

| 字段 | 含义 |
| --- | --- |
| `mode` | `type`＝类型模式，`instance`＝实例模式（默认） |
| `view` | 类型模式下的视图：`graph`＝图形（默认），`list`＝按层分组的列表 |
| `start` | 实例模式的起点，一个 `{className, primaryKey}` 对象；为空时以当前用户为起点 |
| `selected` | 当前选中的节点；它的全部一跳关系显示在右侧 |
| `selectedType` | 当前选中的类型（类型标识，例如 `platform:Action`） |

搜索框里的文字（`query`）只是临时的，不写进地址。

## 看四层平台类详情

1. 切到**类型模式**（顶部模式切换，或让智能体执行「切到类型模式」）。
2. 在图形里点一个类型节点，或切到**按层分组**视图点一行——两种视图共用同一个选中类型，右侧显示同一份只读类详情。
3. 类详情自上而下是：名称、类型标识、所属层、一句话定义；公开属性表（属性名、类型、是否可选、说明）；入向与出向关系（关系名、方向、对端类型，标注「存储」或「推导」）；该类型登记的具名读法与可发起的操作签名；创建与使用规则。

类型节点的数字是当前用户本人能读到的实例数。显示「无权限」表示该类型的读取被属主拒绝，显示「读取失败」表示属主读取出错，显示「尚未接入」表示属主端点还没接上——都不是 0。

## 从类到实例

- **看实例**：产品层五类（基础组件、投影、面板、应用、智能体）的类详情里有「看实例」。对应目录（`/ontology/components`、`/ontology/projections`、`/ontology/panels`、`/ontology/applications`、`/ontology/agents`）在部署里还没接入、或当前用户没有入口准入时，页面顶部会给出提示，页面本身照常可用。
- **选一个作图谱起点**：类详情里点「选一个作图谱起点」，在下方按关键字过滤、翻页挑一个对象；选中后自动切到实例模式，并以该对象作为起点展开一跳关系。某一类型没有列表读取或当前用户无权限时，列表会就地说明，不影响其他类型。

## 实例模式里换起点

三种换法都可同时用：

1. 顶部「切换起点用户」，在右侧挑一个可读用户；
2. 选中图上任意节点后，点顶部「以选中节点为起点」；
3. 右侧「按类型挑选起点」里选类型再挑对象（类型模式下从类详情进入也是这一处）。

顶部「回到当前用户」清掉起点和选中，重新以当前登录用户为起点。

## 图上画什么、怎么筛

- 实线是明确存储的引用关系（含「发布了」），虚线是能从记录推导出来的关系。
- 画布上方的层筛选按事实 / 能力 / 治理 / 产品开关，图例只统计当前已画出的节点；同一层重新打开时会补读这一层的关系。
- 右侧「节点关系」里的「关系种类」筛选通过面板状态与图谱联动，同时过滤画布和右侧关系列表。
- 「没有邻居」「无权读取某类关系」「读取失败」分别显示，互不合并：某个关系被属主拒绝，不影响同一节点其他关系照常显示。

## 搜索只高亮已画出的节点

实例模式的搜索框只把**已经画在画布上**的匹配节点高亮，不会去全库查找，也不会隐藏其他节点。要找还没画出来的对象：切到类型模式，选中它的类型，再用「选一个作图谱起点」按关键字过滤、翻页挑选。

## 选中节点与关系检视

选中图上任意节点（包括投影、面板这类绑定平台类型的节点）后，右侧按关系种类分组列出它的全部入向与出向一跳关系：方向、存储/推导、对端对象与对端类型；关系带有绑定信息时一并显示绑定的读法和操作。点对端名字可以切换选中，点「设为起点」立刻以它重新展开一跳关系。

## 智能体可以怎么做

- 读当前状态：模式、起点、选中节点、选中类型都在地址的 `state` 里，打开页面时也可以带上这些值（例如 `?state={"mode":"type","selectedType":"platform:Action"}`）把页面直接开到某个类型或某个节点。
- 切换视图与模式、「清除选中」「起点回到当前用户」是这个面板自己声明的操作，人和智能体走同一条；让智能体执行对应操作即可。
- 选中某个具体类型时，智能体可以用打开页面时带 `selectedType` 的方式聚焦；选中具体节点时带 `selected`。
