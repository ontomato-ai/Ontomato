# 投影目录：这个页面怎么用

平台自带和本域里读者能使用的投影（SDK 组件 + 它读的数据 + 它登记的操作）。这个页面管理投影本身；面板组合、应用与发布不在这里。
页面上的列表、详情、授权与操作都是属主回答的，这里只写读者和智能体需要知道的、从页面上看不出来的规则。

## 页面在看什么

- 左边的列表是本域里**当前读者有使用授权**的投影，一页一页读（游标翻页，可以换每页条数）。列：名称与说明、所用组件、
  所属人、共享范围、更新时间。
- 范围：`全部`＝有使用授权的全部投影；`我的`＝所属人是当前读者的；`共享`＝所属人不是当前读者的。范围、检索词和排序
  都在地址里，换一次就回到第一页。
- 排序：`最近更新`（默认）或 `名称`。检索同时匹配名称和说明。
- 选中一条后，右边逐项列出这条投影的定义：每个数据项**来处、读法、参数从哪来**；**配置**（组件的配置项）；**输入和输出**；
  **属主登记的操作及目标**；以及**被哪些面板使用**（含读者看不到的面板数量）。
- 原位预览挂载选中投影的当前定义，由平台检查它的使用权。
- `被哪些面板使用` 的条目打开面板目录里那个面板；`查看所属类` 打开能力图谱（`/ontology/assets/capability-map`）的类型列表，深链状态为 `{"mode":"type","view":"list","selectedType":"platform:ProductProjection"}`。平台类来处的链接同样在能力图谱选中实际绑定的类。

## 读写都按读者的真实身份

入口沿用 `ontology-modeling`。列表、详情、使用方都是属主按读者身份、按授权过滤后的答案；写操作也由投影属主裁决。
`record.editable` 为假时页面只读：看不到新建、编辑、复制、删除、授权和共享按钮。读不到（`forbidden`）时说明没有那条投影的使用授权。

## 新建与编辑：只改这次提交的字段

表单是属主自己的 `platform:ProductProjection` 表单（同一个属主表单，`form` 读与 `createForm` 读），保存操作是
`platform:ProductProjection.save`。

- 编辑：当前选中一条投影时打开表单；保存只提交读者改过的字段（JSON Pointer），没提交的字段属主保持原样。读者以表单
  读到的 `revision` 提交，别人同时改过就会被拒。
- 新建：先清掉选中（`selected = null`）再打开同一个表单，属主给的是创建表单；标识由属主生成或沿用草稿给出的 `id`。
- 起草给读者：编辑草稿的入口状态用 `selected` 定位投影，新建草稿用 `creating: true` 打开新建表单。草稿格式和链接用本页技能的
  起草说明。

## 属主登记的操作

这四种写操作都是投影属主登记的，输入形状是属主定的，页面照抄不改：

| 操作 | 输入 | 说明 |
| --- | --- | --- |
| `productProjections.copy` | `{id, name}` | 从选中投影复制一条**私有**的新投影；新标识由调用方给。图投影不能复制，属主会拒。 |
| `productProjections.delete` | `{revision}` | 删除选中的投影。被任何面板使用时属主拒绝（`PRODUCT_IN_USE`），页面列出使用方。 |
| `productProjections.grant` | `{principalKind: principal\|role, principalId, verb: use\|edit}` | 给成员或角色授予使用或编辑权。 |
| `productProjections.revoke` | 同上 | 撤销同样的授权。 |
| `productProjections.share` | `{shared: boolean}` | 开关域内成员的使用授权；`shared: true` 打开，`false` 关闭。 |

删除、复制、授权、共享都作用在**当前选中的那条投影**上，目标来自选中状态，不需要在输入里再写一遍投影标识。
授权是直接提交的：属主只回答成功或拒绝，不返回授权清单，所以页面上没有“当前授权列表”，需要确认时按 ID 与动作查。

## 图投影

`componentId` 是 `@ontomato/sdk:MetricChart` 的投影是看板源卡登记出来的图投影：不能复制，不能改绑组件或指标视图，
编辑只改名称、说明与初始范围，删除和普通投影一样（未被使用时可以删）。要改图本身去看板改源卡。
